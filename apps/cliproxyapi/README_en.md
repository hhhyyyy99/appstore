## Introduction

**CLIProxyAPI** is a proxy server that provides OpenAI/Gemini/Claude/Codex/Grok compatible API interfaces for CLI models, with local or multi-account CLI access for compatible clients and SDKs.

## Features

- **Protocol Compatibility**: Provides OpenAI, Gemini, Claude, Codex, and Grok compatible API endpoints.
- **OAuth Login**: Supports OAuth login flows for OpenAI Codex, Claude Code, Grok Build, and more.
- **Multi-account Load Balancing**: Supports round-robin load balancing across Gemini, OpenAI, Claude, and Grok accounts.
- **Streaming and Tool Calls**: Supports streaming, non-streaming, WebSocket responses, function calls, and multimodal input.
