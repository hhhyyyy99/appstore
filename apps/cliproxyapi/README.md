## 产品介绍

**CLIProxyAPI** 是一个为 CLI 提供 OpenAI/Gemini/Claude/Codex/Grok 兼容 API 接口的代理服务器，可通过本地或多账户 CLI 访问兼容客户端和 SDK。

## 主要功能

- **多协议兼容**：提供 OpenAI、Gemini、Claude、Codex、Grok 兼容 API 端点。
- **OAuth 登录**：支持 OpenAI Codex、Claude Code、Grok Build 等 OAuth 登录流程。
- **多账户负载均衡**：支持 Gemini、OpenAI、Claude、Grok 多账户轮询。
- **流式与工具调用**：支持流式、非流式响应、WebSocket 响应、函数调用和多模态输入。
