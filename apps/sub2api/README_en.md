## Introduction

**Sub2API** is an AI API gateway platform designed to distribute and manage API quotas from AI product subscriptions, handling authentication, billing, load balancing, and request forwarding.

## Features

- **Multi-account Management**: Supports multiple upstream account types such as OAuth and API Key.
- **API Key Distribution**: Generates and manages API Keys for users to access upstream AI services through the platform.
- **Billing and Scheduling**: Supports token-level usage tracking, cost calculation, smart scheduling, and sticky sessions.
- **Admin Dashboard**: Provides a web interface for monitoring, user management, and account management.
